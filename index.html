Frequently Asked Questions About Sprinkler System Design

Is it really free? Do I need an account?
Yes, it's 100% free — no account, no trial, no premium tier. Everything runs in your browser. Nothing is stored on a server. We built it because we needed it ourselves.
What types of sprinkler systems can I design?
The tool supports three sprinkler types: circular (full 360° spray), impact/sector (adjustable arc and radius), and oscillating (rectangular coverage pattern). Set the parameters for each type and see coverage in real time.
How does coverage calculation work?
Monte Carlo sampling. Thousands of random points tested across your lawn to determine exact coverage percentage.
Can I export my design?
One click. Professional PDF with head placement, spray radii, and title block.
Does it work on mobile?
It runs in any modern browser, including mobile. However, for the best experience we strongly recommend using a desktop or tablet — the drag-and-drop interface and canvas precision work much better on larger screens.
